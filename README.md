# AI Career Copilot – Resume Analyzer

An AI-powered resume analyzer that parses PDF/DOCX resumes and generates structured career insights using the Gemini API.

## Features
- Upload resume in PDF or DOCX format
- AI-generated skill gap analysis, learning roadmap & interview questions
- User authentication with session management
- Analysis history dashboard
- Reports stored in TiDB using SQLAlchemy ORM

## Tech Stack
Python | Flask | Gemini API | TiDB | SQLAlchemy | HTML/CSS

## How to Run
```bash
pip install -r requirements.txt
python app.py
```
